## � PHASE 2: Database Setup (Minimal Manual Steps)

**Note:** Database restoration requires SSMS GUI (can't be fully automated), but password reset is automatic.

### Manual Step Only: Restore Databases in SSMS

**User needs to do this (GUI task):**
1. Open **SQL Server Management Studio**
2. Restore the EMR database:
   - Right-click "Databases" → "Restore Database..."
   - Choose "Device", browse to: `Database/2. EMR-Db/FromzaInternationalDB/Dev_DanpheEMR_INT1.bak`
   - Set database name to: `DEV_FromzaEMR_INT`
   - Click OK and wait for restore

3. Create Admin Database:
   - Right-click "Databases" → "New Database"
   - Name: `FromzaAdmin`
   - Click OK

4. Run setup script:
   - File → "Open File..." → `Database/1. Admin-Db/1. FromzaAdmin_CompleteDB.sql`
   - Click "Execute" (green button)

**When done, ask user:** "Have you completed the database restoration in SSMS? (yes/no)"

### Automated Step: Reset Admin Password
**After user confirms databases are restored, run automatically:**

```powershell
# Reset admin password (automated)
sqlcmd -S localhost -d DEV_FromzaEMR_INT -Q "UPDATE RBAC_User SET Password = 'b/ECdMP/loE=' WHERE UserName = 'admin' OR UserName = 'Admin';"

# Verify it worked
sqlcmd -S localhost -d DEV_FromzaEMR_INT -Q "SELECT UserName, Password FROM RBAC_User WHERE UserName = 'admin' OR UserName = 'Admin';"
```

**Report:** "✅ Admin password reset to: admin / pass123"

## 🐛 Automated Troubleshooting

```powershell

    Write-Host "   ✅ SQL Server is running" -ForegroundColor Green

    Write-Host "   ❌ SQL Server NOT running" -ForegroundColor Red
}

# Check 2: Node version

    Write-Host "   ✅ Node v14 confirmed: $nodeVersion" -ForegroundColor Green

    Write-Host "   ✅ EMR database found" -ForegroundColor Green
} else {
    Write-Host "   ❌ EMR database NOT found" -ForegroundColor Red

Write-Host ""
```
